# Мониторинг билетов Gaztelugatxe (28 августа 2026)

Скрипт каждые 5 минут (с 08:00 до ~20:45 по Мадриду) проверяет сайт
public.tiketa.eus на наличие минимум 3 свободных мест в окнах:
- 15:30–16:30
- 17:50–18:30

При находке — шлёт сообщение в Telegram. Работает в облаке через
GitHub Actions, ничего не нужно держать включённым на своём компьютере.

---

## Шаг 1. Создать Telegram-бота

1. В Telegram найди **@BotFather** и открой с ним чат.
2. Отправь команду `/newbot`.
3. Придумай имя бота (например, `Gaztelugatxe Monitor`) и юзернейм,
   заканчивающийся на `bot` (например, `gaztelugatxe_notify_bot`).
4. BotFather пришлёт **токен** вида:
   `123456789:AAExampleTokenXXXXXXXXXXXXXXXXXXXXX`
   Это и есть `TELEGRAM_BOT_TOKEN`. Сохрани его.

## Шаг 2. Узнать свой chat_id

1. Найди своего только что созданного бота в Telegram (по юзернейму) и
   нажми **Start** / отправь ему любое сообщение, например "привет".
2. В браузере открой (подставив свой токен):
   `https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates`
3. В ответе (JSON) найди поле `"chat":{"id": 123456789, ...}` —
   это число и есть `TELEGRAM_CHAT_ID`.

Если ответ пустой — убедись, что действительно отправил боту сообщение
перед этим, и обнови страницу.

## Шаг 3. Создать репозиторий на GitHub

1. Зайди на github.com (если нет аккаунта — зарегистрируйся, это бесплатно).
2. Создай новый **приватный** репозиторий, например `gaztelugatxe-monitor`.
3. Загрузи туда все файлы из этой папки — проще всего через веб-интерфейс
   GitHub: "Add file" → "Upload files", перетащи все файлы и папки
   (включая `.github/workflows/check_tickets.yml`, сохраняя структуру папок).

## Шаг 4. Добавить секреты (токен и chat_id)

1. В репозитории: **Settings → Secrets and variables → Actions**.
2. Нажми **New repository secret**, добавь:
   - имя `TELEGRAM_BOT_TOKEN`, значение — твой токен из шага 1
   - имя `TELEGRAM_CHAT_ID`, значение — твой chat_id из шага 2

## Шаг 5. Включить workflow

1. Перейди во вкладку **Actions** репозитория.
2. Если появится предложение включить workflows — подтверди.
3. Найди workflow **"Check Gaztelugatxe tickets"**, нажми на него,
   затем справа **"Run workflow"** — чтобы проверить, что всё работает,
   не дожидаясь расписания.
4. Проверь, что тебе пришло сообщение в Telegram (либо в логах шага
   "Run scraper" видно "Слот ... plazas" — значит скрипт отработал).

После этого скрипт будет запускаться автоматически каждые 5 минут
с 08:00 до ~20:45 по Мадриду — ничего больше делать не нужно.

## Важно — про надёжность парсинга

Я собрал скрипт по присланным тобой скриншотам страницы, но не смог
протестировать его напрямую на public.tiketa.eus (сайт недоступен
из моей рабочей среды). Логика написана максимально гибко (по тексту
элементов, а не по жёстким CSS-классам), но при первом реальном запуске
могут понадобиться небольшие правки, если вёрстка сайта отличается
от ожидаемой.

Если workflow отработает без ошибок, но не найдёт слоты — в артефактах
запуска (вкладка Actions → конкретный запуск → Artifacts) будут
скриншоты `debug_calendar.png` / `debug_slots.png` с текущим состоянием
страницы на момент сбоя. Пришли их мне — поправлю селекторы.

## Изменить параметры

Все настройки — в начале файла `scraper.py`:
- `TARGET_DAY`, `TARGET_MONTH_LABEL` — дата
- `PEOPLE_NEEDED` — сколько мест нужно найти (сейчас 3)
- `TIME_WINDOWS` — временные окна поиска
